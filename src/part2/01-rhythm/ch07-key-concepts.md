# Key Concepts

This chapter introduces five foundational concepts related to rhythmic notation:

1. **[First Notation: Exact Values Without Measure](./ch07-first-notation.md)** - Preserving ametric conception by avoiding metric frameworks
2. **[Second Notation: Metric Changes (Stravinsky's Method)](./ch07-second-notation.md)** - Frequent time signature changes to accommodate rhythmic irregularity
3. **[Third Notation: Short Measures with Rhythmic Signs](./ch07-third-notation.md)** - Hybrid system combining metric framework with precise durational notation
4. **[Fourth Notation: False Meter with Exact Accentuation](./ch07-fourth-notation.md)** - Conventional metric notation with performance indications to produce intended effect
5. **[Some Metrical Rhythms (Supplementary Examples)](./ch07-supplementary-examples.md)** - Traditional metric rhythms not following systematic innovations
