# Key Concepts

This chapter introduces four foundational concepts related to rhythmic added values:

1. **[Added Value (Valeur Ajoutée)](./ch03-added-value.md)** - Short durational values added to rhythms creating asymmetrical augmentation
2. **[Prime Number Groupings](./ch03-prime-number-groupings.md)** - Rhythmic patterns organized in prime-numbered quantities
3. **[Rhythmic Preparations and Descents](./ch03-rhythmic-preparations.md)** - Temporal gestures analogous to melodic upbeats and terminations
4. **[Connection to Added Notes](./ch03-connection-to-added-notes.md)** - Parametric analogy between rhythmic added values and harmonic added notes
