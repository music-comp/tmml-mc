# Key Concepts

This chapter introduces four foundational concepts related to Hindu rhythmic systems:

1. **[Ametrical Music](./ch02-ametrical-music.md)** - Music organized by precise rhythmic values rather than regular metric framework
2. **[Hindu Rhythmic Systems (Deçî-Tâlas)](./ch02-hindu-rhythmic-systems.md)** - The 120 rhythmic patterns catalogued by Çârngadeva
3. **[Rāgavardhana Analysis](./ch02-ragavardhana-analysis.md)** - Detailed analysis extracting compositional principles from a specific Hindu rhythm
4. **[Prime Number Rhythms](./ch02-prime-number-rhythms.md)** - Rhythmic patterns based on prime-number quantities that resist metric division
